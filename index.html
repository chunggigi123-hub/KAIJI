02방향 · 체결 압력 · 신뢰도

API 키 없이 확인 가능
체결 델타와 데이터 신뢰도 계산 방식
수급은 Binance 완료 1분봉의 거래대금·공격적 매수 거래대금·체결 수를 사용합니다. 개별 체결 로그를 전부 내려받는 방식은 아닙니다. 공격적 매도 거래대금 = 전체 거래대금 − 공격적 매수 거래대금 체결 델타 = 공격적 매수 거래대금 − 공격적 매도 거래대금 매수 비중 = 공격적 매수 거래대금 ÷ 전체 거래대금 최근 완료 5분과 15분을 각각 집계합니다. 진행 중인 1분은 제외하므로 초단위 실시간 델타가 아닙니다. 최근 5분 거래량은 직전 5분과 비교합니다. 표본 기준: 5분 100체결 이상, 15분 300체결 이상. 이는 화면의 보수적 최소 기준이며 통계적 신뢰수준이나 예측 정확도를 보장하지 않습니다. 연속된 완료 봉·최신성·거래대금도 함께 확인합니다. 매수 비중 53% 이상은 매수 우세, 47% 이하는 매도 우세, 사이는 혼조로 표시합니다. 이 경계도 관찰용 규칙이지 검증된 매매 신호가 아닙니다. 모든 수치는 해당 거래소의 해당 선물 계약에 한정됩니다. 체결 델타는 전체 시장 자금 순유입액이 아닙니다.

04종합 분석

기록 저장 없음

BTC를 먼저 분석하고 선택 코인을 별도로 분석합니다. 시장 방향, 실제 체결 압력, 데이터 신뢰도를 구분합니다. 충분하지 않은 체결 자료는 판단 근거에서 제외합니다. 선택 코인에 저장된 보유 포지션이 있으면 자동 연결합니다. 다른 코인의 포지션을 잘못 연결하지 않습니다.
버튼을 누르면 OpenAI API 비용이 발생할 수 있습니다. 시장 데이터와 연결된 포지션 설정이 OpenAI로 전송됩니다. API 키는 브라우저 입력란에서만 사용하고 저장소에 보관하지 않습니다. 공개 배포 서비스에서는 키를 서버에서 관리하는 방식이 더 안전합니다.
분석 대기
먼저 위의 데이터 신뢰도를 확인하세요. 현재 가격과 마크가격이 최신인지 확인한 뒤 분석합니다. 체결 데이터가 부족하면 시장 방향과 수급 판단을 구분합니다. 저장된 포지션은 재입력 없이 연결됩니다. 분석 결과는 이 화면에서만 유지되며 자동 기록하지 않습니다.
비공식 개인용 분석 도구 · 실제 주문 기능 없음
Binance API 접근은 지역·네트워크·브라우저 정책에 따라 제한될 수 있습니다.
안정적인 브라우저 저장을 위해 같은 HTTPS 주소 또는 localhost에서 사용하세요.

분석 방식
• BTC를 항상 먼저 분석
• 선택 코인이 BTC가 아니면 추가 분석
• 완료된 일봉·4시간봉의 가격·거래량만 사용
• 추세·지지저항·거래량·기술지표 확인
• 단기 1~7일 / 중기 1~4주 조건부 전망
• 뉴스·검색·커뮤니티 의견은 사용하지 않음
실행할 때마다 OpenAI API 요금이 발생할 수 있습니다. 두 코인을 분석하면 전송 데이터가 늘어납니다. API 키는 OpenAI 인증에 사용되며, 시장 데이터가 OpenAI로 전송됩니다. 브라우저 직접 입력 방식은 서버 보관 방식보다 키 보호에 불리합니다. 키를 코드·GitHub·스크린샷에 노출하지 마세요.
분석 대기
비트코인은 항상 분석합니다. 관심 코인에서 다른 코인을 선택하면 비트코인 + 선택 코인을 함께 분석합니다. 최근 90일의 일봉·4시간봉을 중심으로 판단하고, 최근 1년 일봉 흐름을 보조적으로 참고합니다. 예측은 확정적인 목표가나 승률이 아닌, 상승·횡보·하락의 조건부 시나리오로 제공합니다.
원작 이미지·로고를 사용하지 않은 비공식 개인용 테마입니다.
바이낸스 공식 서비스가 아니며 주문 기능이 없습니다.
인터넷·API 접근이 필요합니다. 지역·브라우저 정책에 따라 연결이 제한될 수 있습니다.

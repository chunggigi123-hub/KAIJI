파일·브라우저 저장소에 저장 안 함

AI 분석에는 OpenAI API 요금이 발생할 수 있습니다. 선택 코인의 시장 데이터와 추가 참고사항이 OpenAI로 전송됩니다. 개인정보·비밀정보는 입력하지 마세요. 브라우저에서 키를 사용하는 방식은 서버 보관 방식보다 보안상 불리합니다. API 키를 HTML 코드에 직접 넣거나 GitHub에 올리지 마세요.
분석 대기
API 키를 입력하고 코인을 선택한 뒤 분석을 실행하세요. 완료 일봉과 기술지표를 바탕으로 상승·중립·하락 시나리오를 설명합니다. 실시간 뉴스 검색 기능은 없습니다. AI는 미래 가격이나 수익을 보장하지 않습니다.
주문 기능이 없는 개인용 참고 도구입니다. 바이낸스 공식 서비스가 아닙니다.
시세·차트·AI에는 인터넷 연결이 필요합니다. 지역 또는 브라우저 정책에 따라 연결이 제한될 수 있습니다.
